# Portfolio Optimisation Engine

## Architecture

The Portfolio Optimisation Engine constructs optimal portfolios from BUY
recommendations generated by the Recommendation Engine. It is a standalone
module under `src/portfolio/optimizer.py` that integrates with existing
NEPSE Quant Engine components without modifying their public APIs.

```
┌────────────────────┐     ┌─────────────────────┐
│ Recommendation     │────▸│ PortfolioOptimizer  │
│ Engine             │     │                     │
│ (TradeRecommendation)    │ • equal_weight      │
└────────────────────┘     │ • max_sharpe        │
                            │ • min_variance      │
┌────────────────────┐     │ • risk_parity       │
│ RiskEngine         │◀────│ • score_weighted    │
│                    │     │ • confidence_weight │
└────────────────────┘     └─────────┬───────────┘
                                      │
┌────────────────────┐               ▼
│ PortfolioAllocator │     ┌─────────────────────┐
│                    │◀────│PortfolioOptimization │
└────────────────────┘     │      Result          │
                            └─────────────────────┘
```

## Workflow

1. **Input** — receive a list of recommendations (dicts or
   `TradeRecommendation` objects).
2. **Filter** — retain only BUY signals; apply min confidence, min score,
   and max position thresholds.
3. **Validate** — check inputs, correlation matrix, and constraints.
4. **Optimise** — compute weights using the selected method.
5. **Constrain** — clamp weights to `[min_weight, max_weight]` and enforce
   sector limits.
6. **Allocate** — convert weights to capital amounts and share counts.
7. **Report** — return a `PortfolioOptimizationResult` with metrics,
   allocations, and sector exposure.

## Optimisation Methods

### Equal Weight (`optimize_equal_weight`)

Each qualifying position receives an equal weight of `1/N`. Simplest and
most robust method.

### Maximum Sharpe (`optimize_max_sharpe`)

Maximises the Sharpe ratio:
```
Sharpe = (Rp - Rf) / σp
```
where `Rp` is portfolio return, `Rf` is the risk-free rate, and `σp` is
portfolio volatility. Uses scipy SLSQP numerical optimisation. Falls back
to equal weight when scipy is unavailable.

### Minimum Variance (`optimize_min_variance`)

Minimises portfolio variance:
```
Minimise: σp² = wᵀ Σ w
```
where `Σ` is the covariance matrix. Uses scipy SLSQP numerical
optimisation. Falls back to equal weight when scipy is unavailable.

### Risk Parity (`optimize_risk_parity`)

Equalises risk contribution from each position:
```
RCi = wi × (Σw)i / √(wᵀ Σ w)
Target: RCi = RCj for all i, j
```
Uses scipy SLSQP when available, otherwise an iterative coordinate-
descent algorithm.

### Score Weighted (`optimize_score_weighted`)

Weights proportional to each recommendation's score:
```
wi = scorei / Σ scorej
```

### Confidence Weighted (`optimize_confidence_weighted`)

Weights proportional to each recommendation's confidence:
```
wi = confidencei / Σ confidencej
```

## Portfolio Mathematics

| Metric | Formula |
|--------|---------|
| Portfolio Return | `Rp = Σ wi × ri` |
| Portfolio Variance | `σp² = Σ Σ wi × wj × σi × σj × ρij` |
| Portfolio Volatility | `σp = √(σp²)` |
| Sharpe Ratio | `(Rp - Rf) / σp` |
| Diversification Score | `1 - Σ(wi² × σi²) / σp²` |

Where:
- `wi` = weight of position i
- `ri` = expected return of position i
- `σi` = risk (standard deviation) of position i
- `ρij` = correlation between positions i and j

## API Reference

### `PortfolioOptimizer`

```python
optimizer = PortfolioOptimizer(
    capital: float,
    risk_free_rate: float = 0.0,
    max_position_weight: float = 0.25,
    min_position_weight: float = 0.0,
    sector_limit: float = 0.40,
)
```

#### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `capital` | `float` | — | Total investable capital in NPR |
| `risk_free_rate` | `float` | `0.0` | Risk-free rate (decimal) |
| `max_position_weight` | `float` | `0.25` | Max weight per position (0–1) |
| `min_position_weight` | `float` | `0.0` | Min weight per position (0–1) |
| `sector_limit` | `float` | `0.40` | Max exposure per sector (0–1) |

#### Optimisation Methods

All methods share the same signature:

```python
result = optimizer.optimize_<method>(
    recommendations: list[dict | TradeRecommendation],
    correlation_matrix: list[list[float]] | None = None,
    max_positions: int = 50,
    min_confidence: float = 0.0,
    min_score: float = 0.0,
) -> PortfolioOptimizationResult
```

Available methods:
- `optimize_equal_weight()`
- `optimize_max_sharpe()`
- `optimize_min_variance()`
- `optimize_risk_parity()`
- `optimize_score_weighted()`
- `optimize_confidence_weighted()`

### `PortfolioOptimizationResult`

| Field | Type | Description |
|-------|------|-------------|
| `method` | `str` | Optimisation method name |
| `expected_return` | `float` | Portfolio expected return |
| `portfolio_risk` | `float` | Portfolio volatility |
| `sharpe_ratio` | `float` | Sharpe ratio |
| `diversification_score` | `float` | Diversification score (0–1) |
| `capital_used` | `float` | Capital deployed |
| `cash_remaining` | `float` | Unallocated capital |
| `allocations` | `list[PortfolioAllocation]` | Per-position allocations |
| `weights` | `dict[str, float]` | Symbol → weight map |
| `sector_exposure` | `dict[str, float]` | Sector → exposure map |
| `summary` | `str` | Human-readable summary |
| `constraint_violations` | `list[str]` | Constraint warnings |

#### Methods

- `to_dict()` — serialise to dictionary
- `export_csv(path)` — write allocations to CSV

### `PortfolioAllocation`

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | `str` | Stock ticker |
| `weight` | `float` | Portfolio weight (0–1) |
| `shares` | `int` | Number of shares |
| `capital` | `float` | Rupee amount allocated |
| `expected_return` | `float` | Position expected return |
| `risk` | `float` | Position risk (std dev) |
| `sector` | `str` | Sector classification |

#### Methods

- `to_dict()` — serialise to dictionary

### `summary()`

```python
summary = optimizer.summary(result: PortfolioOptimizationResult) -> dict
```

Returns a concise portfolio summary with:
- `method`, `expected_return`, `portfolio_volatility`, `sharpe_ratio`
- `diversification_score`, `positions`, `capital_used`, `cash_remaining`
- `average_position_size`, `largest_position_weight`,
  `smallest_position_weight`, `largest_holding`, `sector_allocation`

### `extract_from_trade_recommendation()`

```python
d = PortfolioOptimizer.extract_from_trade_recommendation(
    recommendation: Any
) -> dict
```

Converts a `TradeRecommendation` (or any object with matching attributes)
to a standard dictionary for input to optimisation methods.

## Input Format

Each recommendation dict should contain:

```python
{
    "symbol": str,           # Stock ticker (required)
    "signal": str,           # "BUY", "HOLD", or "SELL"
    "confidence": float,     # 0–100
    "score": float,          # Recommendation score
    "expected_return": float, # Expected return (decimal)
    "risk": float,           # Risk / standard deviation (decimal)
    "sector": str,           # Sector classification
}
```

`TradeRecommendation` objects are also accepted directly.

## Sector Categories

The engine tracks these NEPSE sectors:

- Banking
- Hydropower
- Finance
- Insurance
- Hotels
- Manufacturing
- Others

## Constraints

| Constraint | Enforcement |
|------------|-------------|
| Max position weight | Clamped and bounded in scipy optimisation |
| Min position weight | Clamped and bounded in scipy optimisation |
| Sector limit | Iterative scaling of over-exposed sectors |
| Max positions | Filtering before optimisation |
| Min confidence | Filtering before optimisation |
| Min score | Filtering before optimisation |

## Correlation Support

When a correlation matrix is provided, it must be an N×N symmetric matrix
with values in `[-1, 1]`. The matrix is used for:

- Portfolio variance calculation
- Covariance matrix construction
- Diversification score computation
- Risk parity marginal contributions
- scipy optimisation objectives

When absent, a default correlation of `0.15` is assumed for all pairwise
relationships.

## Examples

### Basic usage

```python
from src.portfolio.optimizer import PortfolioOptimizer

optimizer = PortfolioOptimizer(capital=1_000_000)

recommendations = [
    {
        "symbol": "NABIL",
        "signal": "BUY",
        "confidence": 85.0,
        "score": 8.5,
        "expected_return": 0.15,
        "risk": 0.20,
        "sector": "Banking",
    },
    {
        "symbol": "CHCL",
        "signal": "BUY",
        "confidence": 72.0,
        "score": 7.2,
        "expected_return": 0.12,
        "risk": 0.18,
        "sector": "Hydropower",
    },
]

# Equal-weight portfolio
result = optimizer.optimize_equal_weight(recommendations)
print(result.to_dict())

# Max-Sharpe portfolio
result = optimizer.optimize_max_sharpe(recommendations)
print(optimizer.summary(result))

# Export to CSV
result.export_csv("portfolio.csv")
```

### With correlation matrix

```python
correlation = [
    [1.0, 0.3],
    [0.3, 1.0],
]

result = optimizer.optimize_risk_parity(
    recommendations,
    correlation_matrix=correlation,
)
```

### With filtering

```python
result = optimizer.optimize_score_weighted(
    recommendations,
    max_positions=5,
    min_confidence=70.0,
    min_score=7.0,
)
```

### From TradeRecommendation objects

```python
from src.recommendations.engine import TradeRecommendation

reco = TradeRecommendation(
    symbol="NABIL",
    signal="BUY",
    confidence=85.0,
    average_score=8.5,

d = PortfolioOptimizer.extract_from_trade_recommendation(reco)

result = optimizer.optimize_equal_weight([reco])
```

| Invalid correlation matrix | `ValueError` |
| Sector limit exceeded | Warning in `constraint_violations` |
| Unknown optimisation method | `ValueError` |
| No recommendations pass filter | `ValueError` |

## Performance Considerations

- **Up to 500 securities** — the engine handles large portfolios efficiently.
- **scipy/numpy** — required for max_sharpe and min_variance optimisation;
  graceful fallback to equal weight when absent.
- **Correlation matrices** — O(n²) storage for the full matrix; manageable
  for portfolios up to ~500.
- **Constraint enforcement** — iterative clamping with bounded iterations
  to prevent infinite loops.
- **Future optimisation** — the dispatcher architecture is designed for
  easy addition of parallel/multiprocessing support.

## Future Enhancements

The engine is designed for easy addition of these methods:

| Method | Type | Description |
|--------|------|-------------|
| Black-Litterman | Bayesian | Combines prior views with market equilibrium |
| Hierarchical Risk Parity (HRP) | Clustering | Uses hierarchical tree clustering |
| Mean-CVaR | Risk metric | Minimises Conditional Value at Risk |
| Equal Risk Contribution | Risk parity | Explicit risk contribution equalisation |
| Kelly Portfolio | Growth | Maximises expected log growth |

To add a new method:

1. Add the method name to `_VALID_METHODS`.
2. Implement a `_weights_<method>()` static/instance method.
3. Add a public `optimize_<method>()` method.
4. Add a dispatch entry in `_compute_weights()`.

## Dependencies

- `numpy` — efficient array operations
- `scipy` — numerical optimisation (SLSQP)

Both are optional; the engine falls back gracefully when they are absent.
